# millefeuille

MILLEFEUILLE — A Policy-Aware, Multi-Layered Memory Architecture for Evolving AI Agents.

Millefeuille is an independent, reusable memory library. **Stage 0 (M0.1)** provides a
durable, append-only observation store backed by SQLite, exposed as a Go library with a
`context.Context`-aware API. It has no HTTP/gRPC server, no authentication, no payload
interpretation, and no vector search — those concerns belong to the hosting application.

## Status

Stage 0 (M0.1). Scope:

- Durable append of observations with idempotent re-append and conflict detection.
- Single-event retrieval by `event_id`.
- Bounded queries filtered by `source_id`, `event_type`, and `received_at` range.
- Versioned SQLite schema migrations (WAL mode).

Out of scope for M0.1: cursor pagination, embeddings, memory promotion, LLM calls,
authentication/authorisation, and any network transport.

## Requirements

- Go 1.26 or later.
- The only non-standard-library dependency is [`modernc.org/sqlite`](https://pkg.go.dev/modernc.org/sqlite)
  (pure Go, CGO-free).

## Usage

```go
package main

import (
	"context"
	"encoding/json"
	"fmt"
	"time"

	millefeuille "github.com/habuka036/millefeuille"
)

func main() {
	ctx := context.Background()

	// Open a file-based SQLite store. In-memory databases are not supported.
	store, err := millefeuille.Open(ctx, "/var/lib/millefeuille/memory.db")
	if err != nil {
		panic(err)
	}
	defer store.Close()

	// Append an observation. received_at is assigned by the library; do not set it.
	receipt, err := store.AppendObservation(ctx, millefeuille.InputObservation{
		EventID:       "01J9Z8K7...", // UUID or ULID, generated by the caller
		SchemaVersion: "0.1",
		SourceID:      "sensor-42",
		DeviceID:      "thermostat-living-room", // optional
		EventType:     "device.status",
		ObservedAt:    time.Now().UTC(),
		Payload:       json.RawMessage(`{"temperature":21.5}`),
		Visibility:    "private", // optional; defaults to "private"
		Provenance: millefeuille.Provenance{
			Origin:     "device",
			TrustLevel: "unverified", // optional; defaults to "unverified"
		},
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("stored %s at %s (hash %s)\n",
		receipt.EventID, receipt.ReceivedAt, receipt.ContentHash)

	// Retrieve a single observation.
	obs, err := store.GetObservation(ctx, receipt.EventID)
	if err != nil {
		panic(err)
	}
	fmt.Printf("payload: %s\n", obs.Payload)

	// Query with a bounded filter.
	page, err := store.QueryObservations(ctx, millefeuille.Filter{
		SourceID:  "sensor-42",
		EventType: "device.status",
		From:      time.Now().Add(-24 * time.Hour),
		To:        time.Now(),
		Limit:     50, // 0 → default 100; > 1000 → capped to 1000; negative → ErrInvalidFilter
	})
	if err != nil {
		panic(err)
	}
	fmt.Printf("found %d observations\n", len(page.Items))
}
```

## API overview

| Method | Description |
|---|---|
| `Open(ctx, path, opts...) (Store, error)` | Open a file-based SQLite store; applies PRAGMAs, runs migrations, verifies WAL. |
| `Store.AppendObservation(ctx, InputObservation) (Receipt, error)` | Durable append; idempotent on identical re-submission; `ErrConflict` on same `event_id` with different content. |
| `Store.GetObservation(ctx, eventID) (*Observation, error)` | Retrieve by `event_id`; `ErrNotFound` if absent. |
| `Store.QueryObservations(ctx, Filter) (Page, error)` | Bounded, ordered query; `ErrInvalidFilter` on negative limit. |
| `Store.Close() error` | Release the database connection. |

### Semantics

- **received_at** is assigned by the library after input validation passes and the
  observation is accepted for storage (UTC). Callers must not set it on input.
- **Idempotency**: re-submitting the same `event_id` with identical content returns the
  original `Receipt`. Re-submitting the same `event_id` with different content (payload,
  visibility, or provenance) returns `ErrConflict`.
- **Append-only**: there is no update or delete API. Observations are immutable once stored
  via the public API.
- **Ordering**: `QueryObservations` returns results ordered by `received_at DESC, event_id DESC`.
- **Payload** must be valid JSON and at most 1 MiB. It is stored verbatim; Millefeuille does
  not interpret its meaning. For idempotency, the payload is normalised (whitespace and key
  order) only when computing the content hash.
- **Timestamps** are stored and returned in UTC with nanosecond precision.

### Errors

Use `errors.Is` against the exported sentinels:

- `ErrNotFound` — no observation for the given `event_id`.
- `ErrConflict` — same `event_id`, different content.
- `ErrInvalidObservation` — missing/empty required field, over-length field, or invalid JSON payload.
- `ErrPayloadTooLarge` — payload exceeds 1 MiB.
- `ErrInvalidFilter` — negative `Filter.Limit`.

## Security notice

Millefeuille performs **no authentication or authorisation of its own**. Read this before
integrating:

- **Trusted-caller model.** Millefeuille is designed to be called from a trusted application
  layer (for example, IMAGO Agent fronted by Guardian for capability authorization and
  audit). Do not expose the `Store` interface directly to untrusted callers.
- **`visibility` is a label, not an access control.** A value of `"private"` is metadata
  stored and returned verbatim. Millefeuille does **not** filter query results based on
  `visibility`; the hosting application must enforce access control at its boundary.
- **Trust is not inferred.** `provenance.trust_level` is stored as supplied by the caller
  (default `"unverified"`). Millefeuille never upgrades or infers trust automatically.
  Do not allow untrusted input sources to set `received_at`, `visibility`, or `provenance`;
  these must be set by the trusted caller.
- **Protect the database files.** The SQLite database file and its associated `-wal` and
  `-shm` files must be protected with appropriate filesystem permissions by the hosting
  application. Append-only semantics apply only to operations through Millefeuille's public
  API; they do not prevent direct modification of the database files and do not provide
  cryptographic tamper evidence in M0.1.
